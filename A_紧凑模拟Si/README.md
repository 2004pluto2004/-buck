# A：紧凑模拟 Si

对应项目大纲第 4 节，以及第 7、8 节中的共同验证与迭代安排。

## 目标与边界

采用 LM25149 内置驱动，先完成单相同步 Buck，再扩展两相交错与均流。重点包括功率器件、磁性元件、电容、电流采样、补偿、热设计与 PCB。

本方向按常规约 0 V 栅源关断设计，第一版不将双 Zener RC 网络加入主驱动路径。Si MOSFET 尚未选定；CSD17576Q5B 仅是教学示例，不能视为最终 BOM。

## 后续工作

- 确认输入实际最大值、瞬态和器件耐压裕量。
- 按实际栅压和热态条件比较功率管，完成电感、电容及损耗计算。
- 设计自举、去耦、栅极电阻、下拉及上电/欠压行为。
- 在器件引脚处验证 VGS、SW、死区、误导通、保护和温升。
- 单相通过验证后，开展两相同步、每相电流观测与真实均流。
