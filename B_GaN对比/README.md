# B：GaN 对比

对应项目大纲第 5 节，并共用第 3、7、8 节的比较条件、验证方法与路线。

## 目标与边界

学习高速驱动和低寄生布局，在统一输入、输出、负载、频率、散热边界及测量方法下，与 Si 方案比较损耗和功率密度。

TPS40400 + LMG1210 + 离散 GaN 是初步架构，尚未确认可直接连接。必须核对驱动输出性质、逻辑电平、参考地、使能、启动、关断和死区。PMP21440 仅用于研究接口方法，不能直接照搬参数。

## 候选状态

- EPC2366：优先评估候选。
- INN040FQ015A、INN040FQ043A：国产候选，需比较导通电阻与栅极电荷等取舍。
- EPC2055 等裸片方案：曾讨论，当前非优先。

上述清单不是采购结论。需结合栅压窗口、实际损耗、封装、钢网与贴装/返修条件确定方案。

## 后续工作

- 先完成控制器与驱动器接口核对，再推进电路设计。
- 保持驱动器、GaN、就近母线电容及自举回路紧凑；SW 不作为长导线跨板接口。
- 独立验证 GaN 驱动，不直接复制 Si 双 Zener 网络。
- 在可比较工况下统计整机损耗、效率和温升，再决定是否提高频率或缩小体积。
