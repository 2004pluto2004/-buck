# C：C2000 数字控制与双 Zener 驱动

对应项目大纲第 6 节，以及第 7、8 节的驱动验证、接口复用和数字控制路线。

## 目标与边界

双 Zener 负压驱动归入本方向，并提前开展硬件验证，无需等待数字闭环完成。C2000 型号、外置半桥驱动器、Si MOSFET 和驱动辅助供电均待选择。

建议路径：C2000 或前期受控 PWM 源 → 输入与使能接口 → 外置半桥驱动器 → RC 分压与双 Zener 网络 → Si MOSFET。功率母线与辅助供电分别定义。

本网络产生的暂态负压不是独立稳压负电源；正负目标栅压需由 MOSFET 要求确定，−2 V 等既有数值仅为示例。原 SiC 分支已取消，不另设第四方向。

## 后续工作

1. 选择 Si MOSFET 和目标 VGS，再确定驱动器、供电、RC 与钳位参数。
2. 依次验证单管、低压半桥、带电感小电流和额定工况。
3. 覆盖启动、欠压、PWM 丢失、复位、停波、占空比突变与长时间关断。
4. 规划 PWM 死区、ADC 同步采样、硬件使能、故障反馈和 Trip Zone 等保护资源。
5. 依次实现受控开环、单相闭环、保护联动与双相均流；更换 PWM 时序后重新验证驱动。

硬件故障关断不得依赖软件循环响应。高速驱动保持本地短回路；可复用计算、接口和测试方法，不强求所有方向共用驱动硬件。
