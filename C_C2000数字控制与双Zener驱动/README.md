# C：C2000 数字控制与双 Zener 驱动

更新日期：2026-10-17。当前器件决策与 [B 方向选型记录](../B_GaN对比/20261017_驱动与GaN选型.md)一致。

## 目标与边界

保留控制器和驱动器分离的结构，提前开展双 Zener 负压驱动硬件验证，无需等待数字闭环完成。当前选定 **UCC27282DRC + 上下管各一颗 EPC2366**，替代此方向早期 Si MOSFET 的器件选择；A 方向模拟 Si 基线独立保留。

路径：C2000 或前期受控 PWM 源 → 输入与使能接口 → UCC27282DRC → RC 偏置与双 Zener 网络 → EPC2366 半桥。功率母线与辅助驱动供电分别定义。C2000 型号、辅助供电电压、RC、Zener 和死区尚待确定。

网络产生的暂态负压不是独立稳压负电源。正向栅压先以 +5 V 为目标，−2 V 保留为待验证的关断负峰值；不能将它写成已实现的稳定负电压。正常负偏压不让负向保护 Zener 反向击穿，仅更深尖峰触发钳位。所有栅压均相对各自源极定义。

## 后续工作

1. 依据 EPC2366 的电气参数确定辅助供电、RC、正负钳位和自举参数，先验证启动首次脉冲及停波重启。
2. 依次验证单管、低压半桥、带电感小电流和额定工况。
3. 覆盖欠压、PWM 丢失、复位、占空比突变与长时间关断。
4. 规划 PWM 死区、ADC 同步采样、硬件使能、故障反馈和 Trip Zone 等保护资源。输入互锁不能替代死区、过流检测和硬件快速关断。
5. 依次实现受控开环、单相闭环、保护联动与两相均流；后续研究可按资源拓展相数，更换 PWM 时序后重新验证驱动。

硬件故障关断不得依赖软件循环响应。高速驱动保持本地短回路；同型号上下管仍需分别验证实际栅压、换流和死区。切换到 C2000 后需保留独立驱动供电，不能默认原模拟控制器的偏置输出继续存在。
