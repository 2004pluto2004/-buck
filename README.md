# 多相 Buck

本仓库以[《多相Buck项目讨论基线 v0.1》](多相Buck项目讨论基线_v0.1_20261014.docx)为项目大纲，按三个研究方向组织。原文档保留在根目录，作为历史讨论基线。当前器件决策以本 README、方向说明和[2026-10-17 驱动与 GaN 选型记录](B_GaN对比/20261017_驱动与GaN选型.md)为准；旧 Word 尚未同步本次变更。

## 共同基线

- 初步标称工作点：12 V → 3.3 V，单相目标 12 A，早期模拟基线频率起点 400 kHz；GaN 方向暂按 800 kHz 评估，尚未锁定，后续是否提升至 1 MHz 由损耗及波形验证决定。
- 自然散热连续运行是目标，环境温度、板尺寸和允许温升待定。
- 后续两相 180° 交错，总输出目标 20 A，每相仍按 12 A 能力设计；这些是设计目标，不是已验证额定值。
- 输入上限、保护阈值及动态指标尚待确认；不得将这些目标表述为已验证能力。
- 当前大纲没有最终 BOM、PCB、样机实测、效率或温升结论。

## 迭代路线

1. V1：A 方向单相模拟基线，同时提前开展 C 方向双 Zener 驱动实验。
2. V2：在单相验证基础上扩展两相模拟交错，加入每相采样、均流和保护。
3. V3：开展 GaN 对比，保持一致的测试边界；顺序可随实验条件调整。
4. V4：C2000 依次实现受控开环、单相闭环、保护联动和双相均流。

## 文件归档约定

三个方向内部后续可按需增加 `docs/`、`calculations/`、`simulation/`、`hardware/`、`tests/`；C 方向另设 `firmware/`。当前只建立方向说明，不以空目录或占位文件表示已有设计成果。

共用指标与验证原则保存在根目录大纲中，方向专属计算、模型、硬件和实测记录归入对应方向。每次迭代注明版本、变更原因、器件状态和需要复验的工况，候选清单与实际装配 BOM 分开管理。
