# 双 Zener 自举驱动参数计算器（离线辅助版）

**主要入口是[通用需求到选型计算流程](../../通用双Zener自举驱动_需求到选型计算流程.md)**。先根据需求选择拓扑、器件和驱动目标，再用本工具核算；本工具不是自动选器件数据库，也不能代替原理图核对、开关仿真和实测。

## 使用

下载完整目录，使用浏览器打开 `index.html`。不需要安装服务器，不调用 CDN，不联网，不上传参数。浏览器没有自动持久化保存：关闭前请“导出项目 JSON”。

- 初次打开为 2026-10-26 的 **12 V → 3.3 V / 500 kHz 初选记录**，不是通过验证的推荐设计。
- “新建自定义”清除器件额定值等参数；输入电压、输出电压、电流、频率、MOS/驱动器额定值、栅压目标、电阻电容、电荷与功耗依据均可修改。
- 换成 48 V → 12 V 等范围时，必须重新选择 MOS、驱动器和相关额定值，不能只改输入输出。
- `presets/epc2366-20261026.json` 是本次预设；`presets/custom-blank.json` 是空白项目。
- 项目 JSON 可导出、重新导入、重置；计算报告为 Markdown，包含公式、数值代入、候选 BOM、约束与未闭合项。

## 计算范围

适用于本项目所讨论的**串联偏置电容 + 双 Zener 栅极偏置/钳位 + 自举驱动**。直接栅极驱动模式仅作不适用提示，不自动套用本网络公式。其他拓扑须先核对原理图。

包含理想 Buck 占空比/周期、补电时间预算、偏置电流和电阻上限、导通路径近似电阻、完整网络电荷自举容量预算、有效容量折算、各电阻自身 RMS 电压功耗及初步额定值检查。理想时间常数不能作为实际补电完成证明。

特别注意：

1. 总网络电荷 `Qnetwork` 包含 MOS 栅极、偏置电容、Zener 与相关电阻支路；不能把已经包含的 `Qg` 再加一次。缺少网络电荷时不计算出“合格”的自举容量。
2. `Qdriver` 必须另给同一最长不补电区间内驱动器自身耗电荷及依据。4 mA 仅保留为全周期平均电流参考；500 kHz 下整周期 2 μs 对应 8 nC 参考，不能由此保证导通 0.55 μs 内只消耗 2.2 nC。工具不会用它自动闭合容量预算。
3. `Ceff = Cnom × (1−容差) × 有效保留系数`，保留系数应基于指定偏压、温度、老化等证据，不能重复扣除已计入的容差。缺少来源不会判定容量闭合。
4. 电阻平均功耗用其**自身完整周期 RMS 电压**平方除以电阻值，不能借另一支路电压替代。额定功耗还须查具体器件温度降额及脉冲能力。
5. D1/D2 是关断支路候选二极管，不是自举充电二极管。GaN 快关断路径仍须核对器件厂商要求。
6. 现有记录包含的 EPC2366、UCC27282 和阻容/二极管料号仅是特定初选示例；工具不证明适合任何其他输入输出范围。改变元件参数后应重新选料。
7. 软件不计算寄生振铃、栅压实际波形、开关损耗和自然散热温升，不是 SPICE/Simulink，不生成硬件安全保证。

任何输出的“预算已列出”都**不等于硬件已验证**；仍需足够的原理图、数据手册、网络电荷、RMS 波形、有效容量、UVLO/补电和温升证据。
